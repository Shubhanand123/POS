# Galla POS

Galla is a point-of-sale app for Indian shops. It handles billing, stock, khata (credit), reports and customers, and it works on phone, tablet and computer.

## What it does

- Scans barcodes with the phone or laptop camera, or with any USB or Bluetooth scanner.
- Lets you add items with a camera photo, a gallery photo or a ready-made picture. Items can be sold as one pack, in many sizes, or loose by weight.
- Shows a real UPI QR code for your UPI ID. It can also confirm UPI payments automatically with a YouPI PG server.
- Shows an Apple-style tick as soon as a payment is confirmed.
- Prints bills (58 mm, 80 mm or A4) and sends them by WhatsApp or SMS.
- Keeps everything saved on the device and works offline. You can export a backup from Settings.

## Run it

Galla is a plain static site with no build step. Serve the folder over **https**; the camera only works on https or localhost.

```
python3 -m http.server 8000   # then open http://localhost:8000
```

To put it on your phone, open the https link, then use **Install app** (Chrome on Android) or **Share → Add to Home Screen** (Safari on iPhone).

## Files

| File | What it is |
|---|---|
| `index.html` | The app screens. This file is generated by `tools/build.py` from `tools/galla-pos.html`. |
| `app.js` | Saving, scanner, camera, item form, UPI QR, YouPI, printing and settings |
| `app.css` | Styles for photos, forms, the camera and printing |
| `sw.js`, `manifest.webmanifest`, `icons/` | Offline support and installing the app |
| `lib/` | qrcode-generator 1.4.4 and @zxing/library 0.21.3 |

To change the screens, edit `tools/galla-pos.html` and run `python3 tools/build.py`.
